# Plantillas de proyecto

Plantillas breves para ejecutar un proyecto de datos e IA. Están rellenadas con el caso ficticio de AgroNova como ejemplo; **adapta los roles y los criterios a tu organización**.

| Plantilla | Para qué sirve | Fase |
|---|---|---|
| `01_charter_del_mvp.md` | Acordar problema, alcance y métrica | Definir |
| `02_matriz_de_fases.md` | Entregable, responsable y criterio de aceptación por fase | Todas |
| `03_definicion_de_terminado.md` | Qué significa «terminado» | Diseñar |
| `04_registro_de_riesgos.md` | Riesgos, controles y señales | Todas |
| `05_solicitud_de_cambio.md` | Decidir un cambio de alcance con costo y fecha | Construir |
| `06_acta_de_aceptacion.md` | Aceptar formalmente la entrega | Validar |
| `07_plan_de_adopcion_y_medicion.md` | Adopción, línea base y medición del valor | Desplegar y medir |
