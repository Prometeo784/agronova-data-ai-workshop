# Charter del MVP

*Ejemplo ficticio: AgroNova.*

| Campo | Contenido |
|---|---|
| Problema (una frase) | La planta se entera del retraso de un proveedor cuando la línea ya se detuvo |
| Usuario y decisión | Compras decide a qué proveedor exigir una acción correctiva |
| Métrica y línea base | OTD por proveedor, medido hoy con la definición acordada (ver `docs/01_caso_agronova.md`) |
| Dentro del MVP | Tablero de OTD por proveedor, carga diaria desde el ERP, controles de calidad con alerta |
| Fuera del MVP (backlog) | Modelo predictivo, RAG documental, tiempo real |
| Supuestos | Frescura diaria suficiente para reprogramar por turno |
| Restricciones | Equipo de una a dos personas; sin acceso al registro interno del ERP |
| Riesgos iniciales | Definición de «a tiempo» sin acordar; Excel de calidad con formatos libres |
| Patrocinador | *(nombre y rol)* |
| Fecha de revisión | *(fecha)* |
