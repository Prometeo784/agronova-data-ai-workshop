# Definición de «terminado» del MVP

Un MVP no está terminado cuando el código corre. Marca cada punto con evidencia:

- [ ] Las cifras clave están **conciliadas** con la fuente (enlace a la evidencia).
- [ ] La definición de cada indicador está **escrita y aprobada** por el usuario.
- [ ] Las pruebas de calidad y el contrato de datos pasan; la cuarentena está bajo el umbral acordado.
- [ ] Hay **alertas con responsable** para frescura, volumen y cuarentena.
- [ ] Los usuarios clave fueron **capacitados** y usan el producto en su proceso real.
- [ ] La **línea base** y el método de medición del valor están documentados.
- [ ] La **aceptación formal** está firmada (ver `06_acta_de_aceptacion.md`).
