# Glosario

| Término | Definición sencilla |
|---|---|
| **BI** (Business Intelligence) | Prácticas y herramientas para analizar datos y apoyar decisiones, como tableros e informes |
| **Bronze, Silver, Gold** | Capas de Medallion: datos crudos con trazabilidad, datos depurados e integrados, y datos listos para consumo |
| **CDC** (Change Data Capture) | Técnica que lee los cambios de un sistema en lugar de copiar todo de nuevo |
| **Chunking** | Dividir un documento en fragmentos para poder buscarlos |
| **Contrato de datos** | Acuerdo sobre esquema, tipos, unidades y calidad esperada entre quien produce y quien consume un dato |
| **Data Warehouse** | Almacén analítico de datos estructurados, pensado para SQL y reportes |
| **ELT** (Extract, Load, Transform) | Primero se carga el dato y luego se transforma en el destino |
| **Embeddings** | Representaciones numéricas de un texto que permiten buscar por significado |
| **ERP** (Enterprise Resource Planning) | Sistema que integra procesos empresariales como compras, inventario y finanzas |
| **ETL** (Extract, Transform, Load) | Primero se transforma el dato y luego se carga en el destino |
| **Idempotencia** | Una carga que, al ejecutarse varias veces, deja el mismo resultado sin duplicar |
| **KPI** (Key Performance Indicator) | Indicador clave con definición y método de cálculo acordados |
| **Lakehouse** | Combina almacenamiento flexible de archivos y tablas con capacidades de consulta y gobierno |
| **Línea base** | Medición previa a la intervención. Sin ella no se puede demostrar mejora |
| **Linaje** | Trazabilidad de dónde viene un dato y por qué transformaciones pasó |
| **LLM** (Large Language Model) | Modelo de lenguaje de gran tamaño, capaz de generar y comprender texto |
| **Marca de agua** | Último valor procesado (por ejemplo, fecha de modificación) que permite cargar solo lo nuevo |
| **Medallion** | Patrón para refinar datos por capas. Es una convención, no una obligación |
| **OC** | Orden de compra |
| **Observabilidad** | Capacidad de ver el estado de datos y procesos: frescura, volumen, esquema, fallos y alertas |
| **Orquestación** | Coordinación del orden, las dependencias y los reintentos de las cargas |
| **OTD** (On-Time Delivery) | Porcentaje de entregas a tiempo (definición correcta en `01_caso_agronova.md`) |
| **Producto de datos** | Conjunto de datos con dueño, contrato, documentación y calidad medida |
| **RAG** (Retrieval-Augmented Generation) | Un LLM responde apoyándose en fragmentos recuperados de fuentes autorizadas |
| **Reconciliación** | Verificar que los totales procesados coinciden con los de la fuente |
| **Atomicidad** | Propiedad de una operación que se completa entera o no deja ningún efecto |
| **Backlog** | Lista priorizada de lo que se hará después, con su costo y fecha estimados |
| **Capital liberado** | Dinero que deja de estar inmovilizado (por ejemplo, en inventario). No es ahorro |
| **Costo de inferencia** | Costo de cada consulta a un modelo de IA, que se mide antes de lanzar |
| **Cuarentena** | Zona donde se guardan los registros rechazados por una validación, con su motivo |
| **Mínimo privilegio** | Cada persona o sistema accede solo a lo que necesita |
| **MVP** | Versión mínima de un producto que ya genera valor |
| **Prompt injection** | Instrucciones ocultas en un dato que intentan manipular a un modelo de lenguaje |
| **Quality Yield** | Unidades aceptadas ÷ unidades inspeccionadas |
| **UPSERT o MERGE** | Operación que actualiza lo que ya existe e inserta lo nuevo |
