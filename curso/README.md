Seis módulos para recorrer, a tu ritmo, lo que la sesión en vivo solo puede mostrar de forma resumida. Cada módulo tiene un objetivo, qué leer, qué hacer y **una comprobación que puedes ejecutar**.

| [M2. Arquitectura y Medallion](M2_arquitectura_y_medallion.md) | ¿Cómo viaja y se refina el dato? | 2 a 3 h | `python curso/checkpoint.py M2` |

| [M6. Ejecutar, adoptar y medir valor](M6_ejecucion_adopcion_valor.md) | ¿Cómo entrego y demuestro valor? | 2 a 3 h | `python curso/checkpoint.py M6` |

\*Los tiempos son **estimaciones del autor**, no mediciones con estudiantes.

## Antes de empezar
- Python y pandas instalados (`pip install -r requirements.txt`). Sin cuentas ni internet.
- Todo el material usa datos y casos **ficticios**. El código es didáctico, no está listo para producción.
- Cada comprobación te dice si lo que hiciste funciona; no te dice que sea válido en una empresa real.

## Cómo avanzar
1. Lee el módulo y el material que enlaza.
2. Haz la práctica.
3. Ejecuta la comprobación. Si falla, el mensaje indica qué prueba no pasó.
4. Anota qué no entendiste: esas dudas son lo más útil que puedes compartir (ver `CONTRIBUTING.md`).
